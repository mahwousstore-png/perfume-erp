# 🤖 استراتيجية تدريب الذكاء الصناعي لنظام التسعير

**الهدف:** تدريب الذكاء الصناعي (Gemini) على طبيعة عمل مهووس للعطور لتحسين دقة القرارات

---

## 📚 1. ما الذي يحتاج الذكاء الصناعي معرفته؟

### أ) **طبيعة العمل:**
الذكاء الصناعي يحتاج فهم:
- **المنتجات:** عطور فاخرة (Luxury Perfumes)
- **السوق:** السوق السعودي
- **المنافسة:** 25+ منافس
- **الهدف:** تسعير تنافسي يحقق أرباح

### ب) **قواعد التسعير:**
- **رفع السعر:** إذا كان سعرنا أقل من المنافس بأكثر من 10%
- **خفض السعر:** إذا كان سعرنا أعلى من المنافس بأكثر من 5%
- **موافق:** إذا كان الفرق ضمن النطاق المقبول (±5%)
- **يحتاج مراجعة:** إذا كانت المطابقة غير مؤكدة (< 85%)

### ج) **العلامات التجارية:**
الذكاء الصناعي يحتاج معرفة 150+ علامة تجارية مثل:
- Dior, Chanel, Gucci, Tom Ford, Creed
- Armani, Versace, Givenchy, Yves Saint Laurent
- Prada, Burberry, Carolina Herrera, Dolce & Gabbana
- وغيرها...

### د) **أنواع العطور:**
- **Eau de Parfum (EDP):** الأقوى (15-20% تركيز)
- **Eau de Toilette (EDT):** متوسط (5-15% تركيز)
- **Eau de Cologne (EDC):** خفيف (2-5% تركيز)

### هـ) **الأحجام الشائعة:**
- 30ml, 50ml, 75ml, 100ml, 125ml, 150ml, 200ml

---

## 🎯 2. كيف ندرب الذكاء الصناعي؟

### **الطريقة الأولى: Fine-Tuning (الأفضل لكن مكلف)**

**الخطوات:**
1. **جمع البيانات:**
   - 10,000+ منتج مع قرارات صحيحة
   - أمثلة على مطابقات صحيحة وخاطئة
   - قواعد التسعير المطبقة

2. **تنسيق البيانات:**
```json
{
  "input": "عطر ديور سوفاج او دو برفيوم 100مل - سعرنا: 450 ريال - المنافس: 480 ريال",
  "output": "موافق - الفرق 30 ريال (6.7%) ضمن النطاق المقبول"
}
```

3. **التدريب:**
   - استخدام Gemini API Fine-Tuning
   - تكلفة: حوالي $50-100 لكل 10,000 مثال
   - مدة: 2-4 ساعات

4. **الاختبار:**
   - اختبار على 1,000 منتج جديد
   - قياس الدقة (يجب أن تكون > 95%)

**المميزات:**
- ✅ دقة عالية جداً (95%+)
- ✅ فهم عميق لطبيعة العمل
- ✅ قرارات سريعة

**العيوب:**
- ❌ مكلف ($50-100 لكل تدريب)
- ❌ يحتاج بيانات كثيرة (10,000+)
- ❌ يحتاج إعادة تدريب عند تغيير القواعد

---

### **الطريقة الثانية: Prompt Engineering (الأفضل للبداية)**

**الخطوات:**
1. **إنشاء Prompt مفصل:**
```
أنت خبير تسعير للعطور الفاخرة في السوق السعودي.

مهمتك: تحليل المنتجات واقتراح قرارات التسعير.

قواعد التسعير:
1. إذا كان سعرنا أقل من المنافس بأكثر من 10% → رفع السعر
2. إذا كان سعرنا أعلى من المنافس بأكثر من 5% → خفض السعر
3. إذا كان الفرق ضمن النطاق (±5%) → موافق
4. إذا كانت المطابقة غير مؤكدة (< 85%) → يحتاج مراجعة

العلامات التجارية المعروفة:
Dior, Chanel, Gucci, Tom Ford, Creed, Armani, Versace...

أنواع العطور:
- Eau de Parfum (EDP): الأقوى
- Eau de Toilette (EDT): متوسط
- Eau de Cologne (EDC): خفيف

المنتج:
{product_name}

سعرنا: {our_price} ريال
سعر المنافس: {competitor_price} ريال
اسم المنافس: {competitor_name}
نسبة المطابقة: {match_score}%

قدم:
1. القرار (رفع سعر / خفض سعر / موافق / يحتاج مراجعة)
2. السبب (شرح مختصر)
3. السعر المقترح (إذا كان رفع أو خفض)
```

2. **إضافة أمثلة (Few-Shot Learning):**
```
مثال 1:
المنتج: عطر ديور سوفاج او دو برفيوم 100مل
سعرنا: 450 ريال
سعر المنافس: 480 ريال
نسبة المطابقة: 92%

القرار: موافق
السبب: الفرق 30 ريال (6.7%) ضمن النطاق المقبول
السعر المقترح: لا حاجة للتغيير

---

مثال 2:
المنتج: عطر شانيل بلو دو شانيل او دو تواليت 100مل
سعرنا: 350 ريال
سعر المنافس: 420 ريال
نسبة المطابقة: 95%

القرار: رفع سعر
السبب: سعرنا أقل بـ 70 ريال (16.7%) - فرصة لزيادة الأرباح
السعر المقترح: 400 ريال
```

3. **التطبيق في الكود:**
```python
def analyze_with_gemini(product_data):
    prompt = f"""
    أنت خبير تسعير للعطور الفاخرة...
    
    المنتج: {product_data['name']}
    سعرنا: {product_data['our_price']} ريال
    سعر المنافس: {product_data['competitor_price']} ريال
    ...
    """
    
    response = gemini_model.generate_content(prompt)
    return response.text
```

**المميزات:**
- ✅ سهل التطبيق
- ✅ مجاني (أو رخيص جداً)
- ✅ مرن (يمكن تعديل القواعد بسهولة)
- ✅ لا يحتاج بيانات تدريب كثيرة

**العيوب:**
- ❌ دقة أقل قليلاً (85-90%)
- ❌ أبطأ قليلاً (يحتاج إرسال Prompt طويل)

### **الطريقة الثالثة: RAG (Retrieval-Augmented Generation)**

**الفكرة:** دمج قاعدة بيانات معرفية مع الذكاء الصناعي

**الخطوات:**
1. **إنشاء قاعدة معرفية:**
   - ملف JSON بجميع العلامات التجارية
   - ملف JSON بجميع قواعد التسعير
   - ملف JSON بأمثلة على قرارات صحيحة

2. **البحث في القاعدة:**
   - عند تحليل منتج، ابحث عن أمثلة مشابهة
   - أرسل الأمثلة مع Prompt إلى Gemini

3. **التطبيق:**
```python
def analyze_with_rag(product_data):
    # البحث عن أمثلة مشابهة
    similar_examples = search_knowledge_base(product_data['brand'])
    
    # إنشاء Prompt مع الأمثلة
    prompt = f"""
    أنت خبير تسعير...
    
    أمثلة مشابهة:
    {similar_examples}
    
    المنتج الحالي:
    {product_data}
    """
    
    response = gemini_model.generate_content(prompt)
    return response.text
```

**المميزات:**
- ✅ دقة عالية (90-95%)
- ✅ مرن جداً
- ✅ يتعلم من الأمثلة السابقة

**العيوب:**
- ❌ يحتاج بناء قاعدة معرفية
- ❌ أبطأ قليلاً

## 📊 4. كيف نقيس النجاح؟

### **المؤشرات الرئيسية:**
1. **الدقة (Accuracy):** نسبة القرارات الصحيحة (يجب > 90%)
2. **السرعة (Speed):** وقت التحليل لكل منتج (يجب < 2 ثانية)
3. **الثقة (Confidence):** نسبة القرارات المؤكدة (يجب > 80%)

### **طريقة القياس:**
```python
def measure_accuracy():
    # اختبار على 100 منتج
    test_products = get_test_products(100)
    
    correct = 0
    total = 100
    
    for product in test_products:
        ai_decision = analyze_with_gemini(product)
        human_decision = product['correct_decision']
        
        if ai_decision == human_decision:
            correct += 1
    
    accuracy = (correct / total) * 100
    print(f"الدقة: {accuracy}%")
```
